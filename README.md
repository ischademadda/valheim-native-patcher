# Valheim Native IL Patcher

Оптимизация Valheim без BepInEx и модов: патчер правит IL в `assembly_valheim.dll` (Mono.Cecil),
а игра запускается нативно на Apple Silicon, без Rosetta. Главный принцип v9 — **vanilla-correct**:
игровая логика, баланс и картинка остаются как в оригинале, убирается только лишняя работа
и баги движка.

*English: an IL patcher (Mono.Cecil) for Valheim's `assembly_valheim.dll` on macOS / Apple Silicon.
It removes wasted CPU/GPU work and fixes engine bugs while keeping gameplay and visuals vanilla.
Client-side only, no BepInEx. Unofficial, not affiliated with Iron Gate.*

## Что нужно

- Valheim из Steam на macOS (`valheim.app`)
- .NET SDK 10 (`brew install dotnet`); скрипты ищут его в `/opt/homebrew/opt/dotnet/libexec`
  или в `$DOTNET_ROOT`
- Репозиторий склонирован **прямо в папку игры**, рядом с `valheim.app`:

```bash
cd ~/Library/Application\ Support/Steam/steamapps/common/Valheim
git clone https://github.com/ischademadda/valheim-native-patcher.git tmp \
  && mv tmp/.git . && rm -rf tmp && git checkout -- .
```

## Использование

Закройте игру перед патчем.

```bash
./start patch v9            # поставить v9 (рекомендуется)
./start patch v9 --profile  # v9 + профайлер (см. ниже)
./start verify              # проверить целостность патча
./start status              # какой патч стоит
./start restore             # вернуть оригинальную dll из .bak
```

Перед первым патчем оригинал сохраняется в `assembly_valheim.dll.bak`. Каждый следующий патч
собирается заново из этого оригинала. После записи `patch.sh` переподписывает `valheim.app`
(`codesign --sign -`), иначе macOS не даст запустить изменённое приложение.

### Автопатч

Steam заменяет dll при обновлении игры и при проверке целостности файлов. Чтобы патч
восстанавливался сам, пропишите в Steam → Valheim → Свойства → Параметры запуска:

```
"/Users/<you>/Library/Application Support/Steam/steamapps/common/Valheim/autopatch.sh" %command%
```

Перед каждым запуском скрипт пересобирает патчер, если исходники изменились, и ставит v9, если
его нет. Игра запускается в любом случае. Лог: `autopatch.log`.

Если после обновления игры патчер пишет `[PATCH ERROR] ... unexpected IL` или `not found`,
значит игра изменилась и патч к ней больше не подходит. Файл игры при этом не трогается.

## Что меняет v9.16

**Исправления багов игры**
- `ZNetScene.RemoveObjects` больше не ломается навсегда, когда объект уничтожен в обход
  ZNetScene (например, звук смерти асксвина). В оригинале после этого со сцены переставали
  выгружаться объекты: их становилось 20k+, и FPS падал до перезапуска.
- Проверка выгрузки зон (`HaveInstanceInSector`) не перебирает все объекты сцены для каждой зоны.
- Удаление navmesh-связей укладывается в бюджет времени. В Туманных землях оно занимало
  до 15 мс за кадр.

**CPU**
- Ограничение догоняющих шагов физики при просадках FPS.
- Перестройка ландшафта распределена по кадрам. Коллизия ландшафта собирается с настройками
  Unity по умолчанию, а сетки строятся без аллокаций.
- Обновление износа построек: не больше 20 деталей за кадр, логика опор ванильная.
- Перестройка navmesh-тайлов в 3 раза реже.
- Туман Туманных земель (`ParticleMist`) переписан: геометрия кэшируется, эмиссия
  распределена по кадрам, частицы под землёй не создаются. Лимит частиц настраивается.
- Быстрое автосохранение (карта сериализуется целиком), DepthCamera не перерисовывает
  неизменившийся вид.
- Лимит эффектов за кадр, лимит дыма и его физических тел, рэгдоллы исчезают через 3.5 с.
  Убрана локализация в EnemyHud каждый кадр. Анимации не считаются вне экрана (кроме игроков, боссов и прирученных).

**GPU (картинка не меняется)**
- Солнечные тени мелких слоёв (эффекты, предметы, мелкий декор, существа) обрезаются ближе
  общей дистанции теней. Ландшафт, постройки и деревья отбрасывают тени на полную дистанцию.
- SunShafts выключаются, пока солнце за пределами экрана: эффект в этом случае и так добавляет ноль.
- Проба отражений рендерится без солнечных теней и обновляется реже, пока игрок стоит на месте.
- Мягкие частицы выключены. Количество и дальность источников света как в оригинале.

Другие версии (`v5`–`v8`) — старые и более агрессивные варианты, их стоит брать только для сравнения.

## Профайлер

`./start patch v9 --profile` встраивает замер времени по подсистемам и фазам Unity PlayerLoop.
Лог пишется в `~/Library/Logs/IronGate/Valheim/native_profile.log`: раз в минуту сводка
(FPS, медленные кадры, топ секций, счётчики draw calls / треугольников / памяти) и строка
на каждый фриз дольше 50 мс с разбивкой по причинам.

Файлы-переключатели в папке с логом (создаются без перезапуска игры):

| Файл | Эффект |
|---|---|
| `mist_off` | выключить эмиссию тумана (A/B-замер) |
| `mist_cap` | доли лимита частиц тумана, например `0.45 0.65` (дальний / ближний) |
| `census_on` | раз в минуту перепись теней по слоям (дорого, 5–50 мс) |

Убрать профайлер: `./start patch v9`.

## Структура

| Путь | Что это |
|---|---|
| `Patcher/` | сам патчер (net10.0, Mono.Cecil): все патчи, `verify`, `ensure` |
| `NativeMist/` | хелпер `NativePatchMist.dll` (туман, рендер-твики, выгрузка зон и объектов); встраивается в патчер и кладётся в `Managed/` |
| `NativeProfiler/` | хелпер профайлера `NativePatchProfiler.dll` (только с `--profile`) |
| `start`, `patch.sh`, `autopatch.sh` | запуск, сборка, переподпись, автопатч из Steam |
| `windows/`, `make-dist.sh` | сборка zip с exe для Windows |

В репозитории нет файлов и кода игры. Хелперы компилируются против вашей локальной копии
`assembly_valheim.dll.bak`.

## Отказ от ответственности

Неофициальный проект, никак не связан с Iron Gate. Патч клиентский: на сервере и у других
игроков его ставить не нужно. Пользуйтесь на свой риск. Перед экспериментами делайте копию
мира и персонажа.
