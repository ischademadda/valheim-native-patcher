Valheim IL Patcher — оптимизация Valheim без BepInEx
====================================================

Патчер правит один файл игры: valheim_Data\Managed\assembly_valheim.dll.
Перед первым патчем он сохраняет оригинал в assembly_valheim.dll.bak,
так что всё откатывается в один клик. .NET ставить не нужно — всё внутри exe.

УСТАНОВКА
---------
1. Steam -> ПКМ по Valheim -> Управление -> Просмотреть локальные файлы.
2. Распакуй папку ValheimPatcher из архива прямо туда, чтобы получилось:
      ...\steamapps\common\Valheim\ValheimPatcher\ValheimPatcher.exe
3. Закрой игру.
4. Запусти "1. Patch v9 (recommended).cmd" двойным кликом.
   В конце должно быть "Result: 12/12 checks verified successfully." и "Done."

Если Windows покажет "Система Windows защитила ваш компьютер" — это потому что
exe не подписан. Нажми "Подробнее" -> "Выполнить в любом случае".
Если пишет "Access denied" — запусти .cmd от имени администратора.

ФАЙЛЫ
-----
1. Patch v9 (recommended).cmd  — поставить патч v9 (рекомендуется)
2. Patch v7 (fallback).cmd     — предыдущая версия, если с v9 что-то не так
3. Status.cmd                  — проверить, стоит ли патч
4. Restore vanilla.cmd         — вернуть оригинальный файл игры
5. Patch v9 + profiler.cmd     — v9 + замер фризов (см. ниже)

АВТОПАТЧ (чтобы патч не слетал)
-------------------------------
Steam -> ПКМ по Valheim -> Свойства -> Параметры запуска, вставь (путь поправь под себя):

  "C:\Program Files (x86)\Steam\steamapps\common\Valheim\ValheimPatcher\ValheimPatcher.exe" ensure v9 -- %command%

Перед каждым запуском патчер проверит, стоит ли v9, и если Steam его затёр — поставит
заново (если стоит — ничего не делает). Игра запустится в любом случае, даже если патч
не встал. Результат пишется в ValheimPatcher\autopatch.log.
Если с этой опцией игра вдруг не стартует — просто сотри её из параметров запуска.

ПРОФАЙЛЕР (если есть фризы)
---------------------------
"5. Patch v9 + profiler.cmd" ставит v9 и замер времени по подсистемам игры.
Поиграй как обычно (лучше час на своей базе), потом скинь файл
  %USERPROFILE%\AppData\LocalLow\IronGate\Valheim\native_profile.log
Там видно, что именно тормозит в каждом подлагивании. Убрать замер: "1. Patch v9".

ВАЖНО
-----
* Без автопатча патч слетает, когда Steam обновляет игру или делает "Проверить
  целостность файлов". Тогда просто запусти "1. Patch v9" ещё раз.
* Если после обновления игры патчер пишет [PATCH ERROR] ... not found —
  игра изменилась и патч к ней не подходит. Файл игры при этом НЕ меняется,
  можно спокойно играть на ванили.
* Патч только клиентский: работает на любом сервере, другим игрокам ставить не надо.

ЧТО МЕНЯЕТ v9
-------------
* Лимит физики при просадках FPS, плавная подгрузка объектов (25/кадр)
* Обновление износа построек: не больше 20 деталей за кадр (логика опор ванильная)
* Трава: 30/35/40 м на Low/Med/High
* Коллизия ландшафта собирается быстрее (меньше фризов при копании и подгрузке)
* Эффекты: не больше 32 за кадр, дальние (>45 м) режутся первыми
* Рэгдоллы исчезают через 3.5 с, меньше дыма, без дрожания источников света
* Точечный свет: максимум 4/10/16 источников (Low/Med/High), soft particles выкл.
* Анимации мирных животных не считаются, когда их не видно

Если игра не найдена автоматически (нестандартная папка Steam), запусти из
командной строки, указав путь:
  "1. Patch v9 (recommended).cmd" --managed "D:\SteamLibrary\steamapps\common\Valheim\valheim_Data\Managed"
